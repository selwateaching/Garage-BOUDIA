Ce document accompagne le test de l'application de gestion d'atelier. Suivez les étapes dans l'ordre une première fois — c'est le circuit réel d'un véhicule, de sa réception à l'encaissement.

00 Réglages 01 Réparation 02 Devis 03 Facture 04 Paiement 05 Clients 06 Planning
00

Régler le garage — une seule fois

Page Paramètres

Avant tout essai, on identifie l'atelier. Ces informations se répercutent automatiquement sur l'ordre de réparation, le devis et la facture.

  1. Ouvrez ⚙ Paramètres depuis n'importe quelle page.
  2. Ajoutez le logo et, si vous en avez un, le tampon du garage.
  3. Renseignez nom, adresse, téléphone, email, et si disponibles NIF / RC.
  4. Cliquez 💾 Enregistrer.
À savoir : ce réglage est propre à cet ordinateur et à ce navigateur — il ne se répète pas ailleurs automatiquement.
01

Réception du véhicule

Ordre de réparation — numéroté automatiquement OR-00001

C'est le constat d'entrée : état du véhicule, niveau de réservoir, dommages repérés sur les schémas, réparations à prévoir.

  1. Dans le champ Client, tapez un nom : si le client existe déjà, ses coordonnées se remplissent seules.
  2. Complétez immatriculation, marque, kilométrage.
  3. Sur les 4 schémas du véhicule, sélectionnez un type de dommage (Enfoncement / Rayure / Cassé) puis dessinez son emplacement.
  4. Faites signer le client et le garagiste dans les cadres prévus.
  5. Cliquez 📋 Passer au devis → — les informations saisies s'y reportent automatiquement.
Le bouton 🌙 Traduire en arabe produit un second PDF pour le mécanicien, réparations traduites automatiquement.
02

Chiffrer le devis

Devis — numéroté D-001, distinct de la facture

Le devis est une estimation : il peut être modifié, réimprimé, sans conséquence sur vos recettes.

  1. Précisez si le client est Particulier ou Entreprise (raison sociale, NIF, RC s'affichent pour une entreprise).
  2. Ajoutez les lignes de Main-d'œuvre et de Pièces — le total HT / TVA 19 % / TTC se calcule seul, en dinars (DA).
  3. Téléchargez-le avec ⬇ Télécharger PDF, ou ouvrez Gmail pré-rempli avec ✉ Envoyer au client (le PDF est à joindre à la main).
03

Émettre la facture

Facture — numérotée séparément F-001

La facture ne peut être émise qu'une fois le devis accepté par le client — c'est ce qui déclenche son entrée dans vos recettes.

  1. Faites signer le client dans le cadre de signature.
  2. Si la signature électronique ne fonctionne pas (écran, souris…), cochez Validation manuelle à la place.
  3. Cliquez 🧾 Émettre la facture — le PDF de facture se télécharge, référençant le devis d'origine.
Sans signature ni case cochée, la facture est refusée — c'est volontaire, pour éviter de compter des brouillons dans les recettes.
04

Encaisser et suivre les recettes

Page Recettes

Chaque facture émise y apparaît, avec son statut de paiement.

  1. Repérez la facture dans la liste — statut Impayé par défaut.
  2. Cliquez + Paiement, saisissez le montant et le mode (Espèces / Virement / CCP / Chèque).
  3. Le statut passe à Partiel puis Payé selon le cumul réglé.
  4. Filtrez par Aujourd'hui / Cette semaine / Ce mois / Tout pour voir le total encaissé et le reste dû.
05

Retrouver un client

Page Clients

Chaque nouveau nom saisi sur un OR ou un devis y est ajouté automatiquement — rien à faire de plus.

  1. Consultez, complétez ou supprimez une fiche existante.
  2. Vous pouvez aussi ajouter un client directement ici, en Particulier ou Entreprise.
Au prochain passage de ce client, taper son nom sur l'OR ou le devis rappelle seul son adresse, téléphone et email.
06

Planifier un rendez-vous

Planning RDV

Depuis un devis, 📅 Planifier RDV ouvre le planning avec le véhicule pré-rempli.

  1. Choisissez un mécanicien, une date, une heure et une durée.
  2. Le calendrier de la semaine affiche les créneaux déjà pris.
  3. Validez avec ✅ Confirmer le RDV.

Fiche de test

Cochez au fur et à mesure — un cas réel complet, du premier accueil à l'encaissement.

À savoir avant de généraliser l'usage

  • Toutes les données (clients, factures, recettes) restent enregistrées dans ce navigateur, sur cet ordinateur — rien n'est partagé automatiquement avec un autre poste.
  • Ne videz jamais le cache / les données de navigation sur ce poste : cela effacerait définitivement l'historique.
  • Un même poste doit rester dédié à l'application pour garder un historique cohérent : dans la configuration actuelle, secrétariat et gérance ne peuvent pas voir les mêmes données en direct sur deux ordinateurs différents.

Besoin de deux postes reliés — secrétariat & gérance ?

C'est possible : accueil et gérance travaillent alors sur les mêmes clients, factures et recettes en temps réel, sur deux ordinateurs distincts. Ce n'est pas inclus dans la version actuelle — c'est une option payante (mise en place d'une base de données partagée), à commander séparément si le besoin est confirmé après ce test.
